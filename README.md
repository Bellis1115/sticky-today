# 今日便利贴

一个轻量的桌面任务便签，适合记录当天待办、按日期整理任务，并保存临时笔记。

## 功能

- 添加任务，可填写日期（`YYYY-MM-DD`）
- 按日期分组显示任务
- 待完成和已完成任务分区显示
- 勾选完成后自动移动到已完成区域末尾
- 点击任务文字选中任务，再使用统一操作栏：上移、下移、编辑、删除
- 编辑任务内容和日期
- 清除已完成任务
- 随手记自动保存，支持滚动和拖动区域边界调整高度
- 随手记支持“另存为”文本文件
- 桌面快捷方式启动，不需要每次打开终端
- 支持自定义应用图标

## 数据保存

任务和随手记默认保存在：

```text
~/.local/share/sticky-today/today.json
```

程序不会主动删除已有数据。迁移或更新前，可以手动备份这个文件。

## Linux 安装

Ubuntu/Debian 需要 Python 3 和 Tkinter：

```bash
sudo apt install python3 python3-tk
```

首次安装在项目目录执行：

```bash
bash install.sh
```

脚本会在桌面创建“今日便利贴”启动图标，并同步安装到用户应用目录。之后直接双击桌面图标即可启动。

如果桌面环境提示启动器不可信，右键图标选择“允许运行”或“信任此启动器”。

开发/调试时也可以直接运行：

```bash
./run.sh
```

## Windows 安装

先安装 Python 3，并在安装时勾选 **Add Python to PATH**。然后双击项目目录里的：

```text
install.bat
```

安装脚本会在 Windows 桌面创建快捷方式，并使用 `pythonw.exe` 启动，因此正常启动不会弹出终端窗口。

如果移动了项目文件夹，需要重新运行 `install.bat` 更新快捷方式路径。

## 操作提示

- 添加任务时，点击日期输入框可以打开日期选择器。
- 点击任务文字可以选中任务；未选中任务时，统一操作栏会处于禁用状态。
- 随手记标题右侧的“另存为”可以将当前内容保存为 UTF-8 文本文件。
- 任务日期为空时，会归入“未设置日期”。

## 项目文件

- `sticky_today.py`：主程序
- `run.sh`：Linux 调试启动脚本
- `install.sh`：Linux 桌面安装脚本
- `install.bat` / `install.ps1`：Windows 桌面安装脚本
- `sticky_today.png` / `sticky_today.ico`：应用图标
